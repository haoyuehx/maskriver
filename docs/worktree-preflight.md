# 可选工作树与本地隔离

项目标准流程是四位成员各自 clone、个人功能分支、PR 与统一 CI，见 [AGENTS.md](../AGENTS.md)。不要求 Native worktree、特定路径或 Pi。

如个人选择 Git worktree 或获授权的 AI 并行工具：

- 每个 writer 使用独立目录，确认当前仓库、分支、基线 SHA 与文件范围。
- 不共享未提交改动，不操作其他人的目录，不以同名目录伪造旧执行状态。
- 工具隔离失败时停止该工具任务，不影响其他成员的独立克隆开发。
- 清理前确认无活动任务、未提交改动已保存；只由设备持有人确认并处理自己的资源。关闭 Issue 不是删除工作树的授权。

`scripts/check-native-worktree.mjs` 是历史设备诊断工具，不是跨平台开发或 CI 门禁，不应在其他机器照搬运行。历史记录中的绝对路径和模型状态只说明当时环境，不约束当前成员。
