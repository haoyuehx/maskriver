## 事实边界（片中已遵守）

1. 五步工作流统一表述为 scan → mask（dry-run 预览）→ approve（Ed25519 记录绑定计划）→ apply → validate。
2. 写入需 `--approved` 声明 + `--apply` 意图 + 有效签名记录三者同时成立。
3. 有界流式、Outbox 回执、Checkpoint/Resume 只出现在本地 SQLite 语境；明确写出 MySQL 流式/恢复不在支持范围。
4. 「确定性脱敏」旁注「不等于匿名化，也不承诺全局无碰撞」。
5. 不出现版本号、里程碑代号、Issue/PR 编号、CI 日志；不宣称存在 Web 管理后台（界面标注为概念工作区 + 合成数据）。
