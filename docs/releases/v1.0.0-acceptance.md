## Accepted risks / limits

See [release notes](v1.0.0.md). No P0/P1 is known open at release publication.
Accepted P2 include: MySQL strict is scoped to visible FKs/planned storage;
MySQL hot-recovery is absent; cross-schema FK invisibility; content digest cost;
local trust boundary is not RBAC; synthetic evaluation is not production
accuracy; Windows/macOS streaming and WAL recovery unsupported.
